# Achyuta.ai - Business & Life AI Assistant 🚀

Achyuta AI aapke poore business ko manage, automate aur protect karne ke liye banaya gaya ek powerful background assistant hai. Iska naam Bhagwan Vishnu ke **"Achyuta"** (Infallible / Jo kabhi na gire / Error-free) roop se inspired hai.

## ✨ Features:
1. **Background Global Shortcut (`Ctrl + A`)**: Aap apne computer par kahin bhi hon (coding kar rahe hon, browser par hon, ya kuch bhi kaam kar rahe hon), jaise hi aap **`Ctrl + A`** press karenge, Achyuta ka smart interface turant aapke samne pop-up ho jayega!
2. **Business Management & Automation**: Yeh aapke business queries, sales analytics, aur tasks ko handle karta hai.
3. **Voice Response (TTS)**: Achyuta aapko sirf text nahi balki voice mein bhi reply dega.
4. **Lightweight & Always Active**: Background mein silently run karta hai bina aapke PC ko slow kiye.

---

## 🛠️ Kaise Run Karein?

1. **Requirements Install Karein:**
   Pehli baar run karne ke liye terminal / command prompt mein yeh command chalayein:
   ```bash
   pip install keyboard pyttsx3
   ```

2. **Assistant Start Karein:**
   Aap seedhe **`start_achyuta.bat`** file par double click kar sakte hain, ya terminal mein yeh command run karein:
   ```bash
   python run.py
   ```

3. **Use Kaise Karein:**
   - App khulte hi background mein listener chalu ho jayega.
   - Jab bhi aapko Achyuta se baat karni ho, apne keyboard par **`Ctrl + A`** dabayein.
   - Achyuta window screen par a jayegi, apna message type karein aur enter dabayein!
